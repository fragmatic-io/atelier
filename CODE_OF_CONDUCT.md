# Code of Conduct

CIR adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. The full text is canonical and lives at that URL; the summary below is for orientation only.

## In short

We are committed to making participation in this project a respectful experience for everyone, regardless of background or identity. We expect contributors to:

- Be considerate and constructive in disagreements
- Give and accept feedback gracefully
- Take responsibility for mistakes and learn from them
- Focus on what is best for the community and the project

We will not tolerate sustained disrespect, personal attacks, or behavior that makes other contributors feel unwelcome.

## Reporting

If you experience or witness unacceptable behavior, contact the maintainers at **conduct@cir.dev** (placeholder until a real address is established — open a private GitHub security advisory in the meantime).

Reports will be reviewed and investigated promptly and fairly. Maintainers are obligated to respect the privacy and safety of the reporter.

## Enforcement

Maintainers will follow the [Community Impact Guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines) from Contributor Covenant 2.1 when determining consequences for any action they deem in violation of this Code of Conduct.

## Scope

This Code of Conduct applies to all project spaces — issues, pull requests, discussions, code review, chat, and any other project-affiliated venue — and to public spaces when an individual is officially representing the project.
