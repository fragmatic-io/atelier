The demo boots end-to-end **without** an LLM key — the `FallbackCompiler` ships hand-written manifests so every code path runs offline.

## 1. Clone and install

```bash
git clone https://github.com/fragmatic-io/atelier.git
cd atelier
pnpm install                                              # ≈ 60s
```

## 2. (Optional) seed an API key

Without a key, the `FallbackCompiler` renders the demo. With one, the `GeminiCompiler` takes over and you watch tokens tick in the audit stream.

```bash
cp apps/demo/.env.local.example apps/demo/.env.local
# add GEMINI_API_KEY=... if you have one
```

## 3. Boot the demo

```bash
pnpm demo
# vault: http://localhost:4001  (consent UI lives here)
# demo:  http://localhost:3000  (lands on /onboarding for a clean profile)
```

`pnpm demo` is the orchestration script — it spawns `atelier vault dev` (the intent vault server) and `next dev` with prefixed log streams.

**First-boot path**: `/onboarding` → vault consent UI → token minted → `/today` rendered with intent-honoured manifest.

## 4. See the manifest compile

In a second terminal, tail the audit stream and watch every compile, policy validation, and dispatched action:

```bash
pnpm atelier dev --tail-only
# tails /api/cir/audit/stream
```

Trigger an SSE recompile from a third shell to see invalidation and re-render at runtime:

```bash
curl -XPOST http://localhost:3000/api/triggers/publish \
  -H 'content-type: application/json' \
  -d '{"type":"user.recompile_route","user_id":"demo-user","manifest_id":"m_demo_today","route":"/today"}'
```

## 5. Write a recipe

Recipes (`recipes/<name>.json`) declare the persona's intent surfaces, granted capabilities, candidate skills, and policy obligations. **The recipe is what humans author. The manifest is what the LLM produces from it.**

```bash
pnpm atelier compile fixtures/intent.json \
  --capabilities capabilities/ \
  --components components/registry.json
pnpm atelier inspect manifests/m_xyz.json
```

## 6. Verify the whole tree

```bash
pnpm validate                 # license + typecheck + lint + format + tests
pnpm test                     # vitest (3000+ tests at HEAD)
pnpm exec cir-evals run       # eval suite
```
