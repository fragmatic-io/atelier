Wave Int-3 ships a global keyboard registry, a Cmd+K command palette, and platform-aware hotkey rendering. Components register actions with the registry; the palette auto-discovers them; the user gets a Linear-quality keyboard surface on every Atelier app.

## The package

`@atelier/keyboard` ships:

- `InMemoryKeyboardRegistry` — the registry implementation.
- `InMemoryRecencyTracker` — weights palette results by use frequency.
- A platform-portable hotkey parser/matcher (`cmd+k` ↔ Meta on macOS, Ctrl on Windows/Linux).

## The `<KeyboardProvider>`

```tsx
import { KeyboardProvider } from '@atelier/components';
import { InMemoryKeyboardRegistry } from '@atelier/keyboard';

const registry = new InMemoryKeyboardRegistry();

function App() {
  return (
    <KeyboardProvider registry={registry}>
      <YourAppRoot />
    </KeyboardProvider>
  );
}
```

One provider at the root. Components register their actions; the provider fans out keyboard events.

## The `useKeyboardAction` hook

```tsx
import { useKeyboardAction } from '@atelier/components';

function Sidebar({ onToggle }) {
  useKeyboardAction({
    id: 'sidebar.toggle',
    label: 'Toggle sidebar',
    hotkey: 'cmd+b',
    icon: 'panel-left',
    handler: onToggle,
  });
  return /* ... */;
}
```

The hook registers when the component mounts; deregisters on unmount. The palette picks it up automatically.

## The `<CommandPalette>`

```tsx
import { CommandPalette } from '@atelier/components';

<CommandPalette />              // auto-discovers from the registry
<CommandPalette commands={[/* explicit override */]} />
```

When the user hits Cmd+K (or Ctrl+K), the palette opens. It renders:

- **Recency-weighted fuzzy match** of the user's query against registered actions.
- **Platform-formatted hotkey hint chips** (`⌘K` on macOS, `Ctrl+K` on Windows/Linux).
- **Lucide icons** via the Vis-3 resolver.

Hit Enter on a result; the registered handler fires.

## The ambient palette

Aurora wires `<AmbientCommandPalette>` once at the layout root:

```tsx
// app/layout.tsx
import { AmbientCommandPalette } from '@atelier/components';

export default function Layout({ children }) {
  return (
    <KeyboardProvider registry={registry}>
      {children}
      <AmbientCommandPalette />
    </KeyboardProvider>
  );
}
```

Cmd+K opens it from anywhere in the app. No per-route wiring.

## What components auto-register actions

| Component        | Action                               | Default hotkey |
| ---------------- | ------------------------------------ | -------------- |
| `Sidebar`        | `sidebar.toggle`                     | (none)         |
| `BulkActionBar`  | `bulk.clear`                         | `Escape`       |
| `Modal`          | `modal.close`                        | `Escape`       |
| `Drawer`         | `drawer.close`                       | `Escape`       |
| `CommandPalette` | `palette.open`                       | `cmd+k`        |
| Custom           | (whatever you register via the hook) | (configurable) |

The hotkey is optional; some actions are palette-only.

## Capability dispatch via the palette

The palette can dispatch capabilities directly:

```tsx
useKeyboardAction({
  id: 'thread.archive.current',
  label: 'Archive current thread',
  hotkey: 'e',
  capability: 'thread.archive',
  inputBuilder: () => ({ thread_id: currentThreadId }),
});
```

Hit `e` (or open the palette + search "archive"); the action dispatcher runs `thread.archive` with the current thread id. Optimistic UI + undo toast follow automatically.

## Recency weighting

The `InMemoryRecencyTracker` records every dispatched action. Subsequent palette opens rank recently-used actions higher. Linear's exact pattern.

## Chord shortcuts (Int-7, roadmap)

Linear's `g i` (go to inbox) and Raycast's user-defined aliases. Int-7 adds a chord state machine to the registry plus a per-user alias overlay stored in the intent vault. Status: roadmap. Wave 11 / Int-7.

## The platform-portable matcher

```ts
import { matchHotkey } from '@atelier/keyboard';

matchHotkey('cmd+k', { ctrl: false, meta: true, key: 'k' }); // true on macOS
matchHotkey('cmd+k', { ctrl: true, meta: false, key: 'k' }); // true on Windows/Linux
```

The string `cmd` resolves to whichever platform-canonical modifier the user is on. Authors don't write per-platform branches.

## The `<KeyboardHint>` chip

```tsx
import { KeyboardHint } from '@atelier/components';

<KeyboardHint hotkey="cmd+k" />;
//   renders: ⌘K  (or "Ctrl+K" on non-mac)
```

Used inline in tooltips, palette items, button affordances.
