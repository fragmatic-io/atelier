Wave Nav-2 ships `usePersistedState` — an SSR-safe hook with three persistence scopes (`session`, `local`, `vault`) and optional cross-tab sync. `<Sidebar>` consumes it for collapse memory; the same hook backs scroll position, filter chips, and saved-view selection across the catalog.

## The hook

```tsx
import { usePersistedState } from '@atelier/react';

function MyComponent() {
  const [value, setValue] = usePersistedState('my-key', initialValue, {
    scope: 'local', // 'session' | 'local' | 'vault'
    crossTabSync: true, // listen for `storage` events
  });

  return /* ... */;
}
```

Three scopes:

- **`session`** — `sessionStorage`. Survives reload; lost on tab close.
- **`local`** — `localStorage`. Survives across browser sessions.
- **`vault`** — vault-backed via `PersistedVaultContext`. Survives across devices when the user signs in on a new one.

## SSR-safety

```ts
const [value, setValue] = usePersistedState('key', initial, { scope: 'local' });
```

On the server, `value === initial` (no `window`). The hook reads from storage on first client render. No hydration mismatch — the hook reconciles via `useEffect`.

## `<Sidebar>` integration

```tsx
<Sidebar
  storageKey="app.sidebar"
  collapseHotkey="cmd+b"
  // ... tree props
/>
```

Two persisted state slots are namespaced under `storageKey`:

- `app.sidebar.collapsed` — boolean (sidebar fully collapsed)
- `app.sidebar.expanded` — JSON id-set (which tree nodes are expanded)

Both default to `local` scope. Pass `storageScope="vault"` to put them in the vault instead (the user's preferred sidebar shape follows them across devices).

## Auto-registration with the keyboard registry

When a `<KeyboardProvider>` is in scope, `<Sidebar>` registers `sidebar.toggle` so Cmd+K palettes discover it (Int-3 integration). The user types "sidebar" in the palette and Enter toggles it.

## The `PersistedVaultContext`

```tsx
import { PersistedVaultContext, type PersistedVaultClient } from '@atelier/react';

function App() {
  const vaultClient: PersistedVaultClient = {
    read: (key) => fetch(`/api/persist/${key}`).then((r) => r.json()),
    write: (key, value) =>
      fetch(`/api/persist/${key}`, { method: 'PUT', body: JSON.stringify(value) }),
  };

  return (
    <PersistedVaultContext.Provider value={vaultClient}>
      <YourAppRoot />
    </PersistedVaultContext.Provider>
  );
}
```

Pass a client; `usePersistedState({ scope: 'vault' })` calls through. When no client is wired, `vault` scope falls back to `localStorage` with a one-time console warning.

## Cross-tab sync

```ts
const [theme, setTheme] = usePersistedState('app.theme', 'light', {
  scope: 'local',
  crossTabSync: true,
});
```

When tab A changes the value, tab B receives a `storage` event and updates its state. Useful for theme toggles, sidebar collapse, anything where two tabs would otherwise drift.

## Pattern: persisted scroll position

```tsx
import { usePersistedState } from '@atelier/react';

function ListView() {
  const [scrollY, setScrollY] = usePersistedState(`scroll:${route}`, 0, {
    scope: 'session',
  });

  useEffect(() => {
    window.scrollTo(0, scrollY);
    const onScroll = () => setScrollY(window.scrollY);
    window.addEventListener('scroll', onScroll);
    return () => window.removeEventListener('scroll', onScroll);
  }, []);

  // ...
}
```

Scroll position survives back-navigation. Linear and Slack both ship this; it's a small but felt-everywhere quality bump.

## Pattern: filter chips

```tsx
function IssueListPage() {
  const [filters, setFilters] = usePersistedState(
    `filters:${route}`,
    {
      assignee: null,
      label: null,
      status: 'open',
    },
    { scope: 'session' },
  );

  // ...
}
```

The user's filter state survives navigation. Combined with the breadcrumb trail (Nav-4), you get a deep-linkable, persistent navigation surface.
