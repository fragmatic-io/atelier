The marketplace LLM eval gate compiles the top-N personas through real Gemini every
night and records token + cost telemetry per persona. This page summarises the trailing
window so cost regressions are visible at a glance.

## Persona source

The gate reads personas from one of two sources, picked by `marketplace-eval-llm.yml`:

- **Local fixtures (default)** — `pnpm marketplace:eval --local-fixtures recipes`
  walks the in-tree `recipes/` directory, parses each `*.json` / `*.recipe.json`
  file as a recipe, and synthesises a canonical `atelier://local/<file>@1.0.0`
  address per persona. Signature verification is skipped (local files are unsigned)
  and `signature_verified: false` is recorded on every persona slot. Use this when
  no hosted vault corpus exists yet — the default the workflow runs.
- **Hosted vault** — `pnpm marketplace:eval --vault-url <url>` fetches signed bundles
  over HTTP from a vault server. Verifies the ed25519 signature and records
  `signature_verified: true` per persona. Set the `MARKETPLACE_VAULT_URL` repo
  secret to flip the workflow into this mode.

The compile + validation pipeline (schema parse, route compile, policy stack,
shape hash) is identical across both sources — the only observable difference is the
`signature_verified` flag and the synthesised vs. fetched address.
