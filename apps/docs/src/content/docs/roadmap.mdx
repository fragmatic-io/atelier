## What's shipped

In order of recency:

- **Marketplace pivot (Wave M)** — 12 commits across the 2026-05-02 session. ETHOS principle #11 codified. All three demos ship zero custom bindings.
- **C-1 (validation feedback loop)** — `497e99d`. `ValidationFeedbackCompiler` mirrors `BudgetMeteredCompiler` wrapper pattern. Cumulative `token_cost`/`duration_ms`/reasoning across attempts. Cascade-friendly via `CompilerOutputError`.
- **C-2 (tool-using compiler MVP)** — `ToolUsingCompiler` wraps `GeminiAgentClient`. Nine tools: `lookupCapability` / `findCapability` / `listCapabilities`, `findComponent` / `inspectComponent` / `listComponents`, `validateDraft`, `inspectExistingManifest` / `listSiblingRoutes`. Default-on as of TODO P1.1 (2026-05-04); opt out via `ATELIER_COMPILER_TOOLS=off`.
- **N-4 (marketing site)** — `fe240d5`. `apps/marketing/` (5 pages). `actions/deploy-pages@v4` workflow. Vanilla CSS + `prefers-color-scheme` dark mode.
- **S-2 (virtualization)** — `<VirtualList>` + `<VirtualTable>` under `@tanstack/react-virtual`. `CursorPaginatedResult` envelope on `DataBinding`. New `Capability.expected_count?` field. Catalog 65 → 67.
- **S-6 (compile cost budget)** — `bc92956`. `BudgetMeteredCompiler`, `BudgetCounter`, `mergeCompileBudgets`, `BudgetExceededError.code`.
- **P-8 (composition policy for empty/loading/error states)** — `7589281` + `1bc2174`. Schema slots + walker substitution + demo showcase.
- **P-9 (information hierarchy / salience)** — Categorical `Capability.salience_level` + intent `priority_overrides` + `resolveSalience` helper + `salienceResolved` advisory policy + `salience-aware-rendering` skill + data-resolver auto-emphasis.
- **Vis-1 (typography depth)** — Letter-spacing / line-height scales + opentype flag map. `<Table>` numeric columns + `<StatCard>` values emit `data-tnum="true"`.
- **Vis-2 (dark mode across 65 components)** — Every entry in `_variants.ts` ships paired light + `dark:` Tailwind utilities. Regression gate.
- **Vis-6 (density toggles per surface)** — `density-aware-rendering` skill + `IntentProfile.density_overrides` + `resolveDensity(intent, route)` + per-route `data-cir-density`.
- **Int-2 (Tooltip)** — 400ms delay, 100ms re-show window. Edge-flip + viewport clamp. `prefers-reduced-motion` honoured.
- **Int-3 (keyboard registry + Cmd+K)** — `@atelier/keyboard` + `<KeyboardProvider>` + `<CommandPalette>` with auto-discovery + recency weighting + lucide icons via Vis-3 resolver.
- **Int-4 (optimistic UI default)** — `5b882fe`. `useOptimisticAction` auto-wires for `reversible: true && low_stakes: true`.
- **Int-8 (undo toast on every destructive action)** — `withUndo()` middleware. `<Toast variant="undo">`. `useUndoToastEmitter()`. Aurora wired.
- **Int-9 (bulk-action floating bar)** — Wired across `List` / `Table` / `Grid` / `Queue` and S-2 Virtual variants. Multi-select + Shift-range + auto-mount.
- **Int-13 (hover card)** — `e4f7d31` (Wave 7c).
- **Cnt-1 (code rendering at depth)** — Shiki as optional peer dep. Lazy per-language grammar load. Dual-theme render. New `language` / `theme` / `foldable` / `highlightLines` / `linkLines` props on `<CodeView>`.
- **Cnt-8 (inline code-block with language detection)** — `73cd9c5`.
- **Nav-2 (sidebar persistence)** — `usePersistedState` (`session` / `local` / `vault`) + `<Sidebar storageKey>` + `PersistedVaultContext`.
- **Nav-3 (sticky pinned content)** — Closed the gap on `<Queue>`; per-item `pinned: true` partitions + sticks.
- **Nav-4 (breadcrumb trail with shareable URLs)** — `TrailSegment` + `serializeTrail` / `parseTrail` (`?_trail=` wire format) + `<Breadcrumb trail={...}>` + `useTrail`.
- **V-1 (intent vault backend)** — `@atelier/vault-server` + `@atelier/vault-client`. ed25519 JWTs + JSON-file storage.
- **V-3 (consent UI)** — Vault renders OAuth-style consent screen; CSRF bound by HMAC nonce. Per-jti revocation cascades `system.security_revocation`.

## What's planned

### Wave C — compiler evolution

- **C-3 / S-1** — Two-stage compile. New package `@atelier/capability-resolver`. Trigger: first host with >150 capabilities. **2 wk. HIGH.**
- **C-4** — Outline agent for multi-route apps. Bounded multi-agent. **1 wk.** Trigger: V-6.
- **C-5** — Marketplace retrieval (RAG). `findRecipe` tool. **2 wk.** Depends on V-6.

### Wave 7 — personalisation

- **P-3** — Refinement loop (right-click → tweak → diff-compile). **1.5 wk.**
- **P-4** — Engagement signals back into compiler. **1 wk.**
- **P-7** — Motion / view-transitions / animation layer. **1.5 wk.**

### Wave 10 — scale tracks

- **S-3** — Streaming subscriptions on `DataResolver`. `resolver.subscribe(binding)` returns `AsyncIterable<T>`. **1.5 wk. MEDIUM.** Gates Coll-1..5.
- **S-4** — Distributed `TriggerBus`. **1-2 wk. HIGH for multi-region.**
- **S-5** — Hierarchical capability registry + generated index + incremental validation. **1 wk. MEDIUM.**
- **S-7** — Capability vector embeddings (RAG variant of S-1). **3 wk. LOWER.**

### Wave 8 — vault marketplace

- **V-6** — Marketplace primitives (addressing, signing, TOFU). **4-6 wk.** The marketplace pivot was the architectural prerequisite.

### Wave 11 — visual depth (selection)

The full track is ~50 items spanning Vis / Int / Cnt / Nav / Coll / AI. Highlights:

- **Vis-3** — Icon resolver + `<Icon>` integration. **1 wk.**
- **Vis-4** — Variant pass for the remaining 32 components. **1.5 wk.**
- **Vis-5** — Custom illustration support. **2 wk.**
- **Vis-7** — Elevation / surface system. **3 d.**
- **Int-1** — Motion layer extension beyond P-7. **2 wk on top of P-7.**
- **Int-7** — Chord shortcuts + per-user aliases. **1 wk on top of Int-3.**
- **Cnt-2** — Diff rendering (Linear/GitHub-style). **1.5 wk.**
- **Cnt-3** — Mention / @user / #issue / link auto-resolution. **2 wk.**
- **AI-1** — "Ask AI" on selection. **2 wk.**

### Wave 12+ — multi-platform + marketing

- **N-1** — iOS SwiftUI native renderer. **4-6 wk.**
- **N-2** — Android Jetpack Compose native renderer. **4-6 wk.**
- **N-3** — React Native bindings. **2-3 wk.**
- **N-5** — Cross-platform component variant authoring. **2 wk.**

## What we explicitly do NOT do

- Flat Plan→Compose→Validate→Refine multi-agent pipeline as the default.
- Per-component specialist agents.
- Free-form agent loops with conversation between agents.

These are documented in `docs/build-plan.md` and `docs/open-questions.md` for future reference.
