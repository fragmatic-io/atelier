> **Capabilities and skills are the public artifact.**
> **Intent is the private artifact.**
> **UI is ephemeral output.**

Software ships **capabilities and skills** (typed actions, data, usage knowledge). Users keep **intent** (preferences, lenses, rules). Agents emit **UI as ephemeral output** — a `Manifest` JSON document the runtime renders. Cached. Versioned. Recomputed only on trigger.

Atelier is the integration of pieces that already exist — MCP-style capabilities, skills, JSON manifest UI, intent profiles, multi-tier caching, pub-sub triggers — into one principled architecture. **Compile rarely, render constantly.**

## What is Atelier?

Atelier is the product brand. The architectural pattern underneath is **CIR** — Capability, Intent, Render. A small, well-structured catalog of UI primitives plus an LLM compiler can produce any domain UI from a recipe + the user's intent profile + the granted capabilities.

The bet: the next decade of software is built on **capability surfaces** and **ephemeral interfaces**, with users (or agents acting for them) composing what they actually need from a stable substrate.

The interface is not the product. The capability is.
