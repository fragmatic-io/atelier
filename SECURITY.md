# Security policy

The supported security model is documented in [`platform/SECURITY.md`](platform/SECURITY.md) and [`platform/docs/THREAT_MODEL.md`](platform/docs/THREAT_MODEL.md).

Do not open a public issue for a vulnerability. Use a private GitHub security advisory or email **v@fragmatic.io**. Include the affected commit/version, reproduction steps, impact, and whether disclosure credit is desired. Never attach customer credentials, raw API payloads, private transcripts, or runtime databases.

The superseded root pnpm/CIR implementation is not supported and receives no security fixes. Only code under `platform/` is in the current product scope.
